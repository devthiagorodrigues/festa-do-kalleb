# Mobile First

Projetar primeiro para ~390×844 px.

- uma coluna
- títulos grandes
- safe area lateral 20–24px
- botões com mínimo 48px
- seções entre 80vh e 110vh quando fizer sentido
- não depender de hover
- swipe em galerias
- scroll narrativo
- lazy loading
- WebP/AVIF
- animações via transform/opacity
- respeitar prefers-reduced-motion

No desktop, recompor o layout; não apenas esticar o mobile.
