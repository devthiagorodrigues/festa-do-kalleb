# Sugestões de presentes

Não criar sistema de reserva. Não marcar item como escolhido. Não pedir ao convidado o que comprou.

## Opções
- **Roupinhas — tamanho 1–2**
- **Sapatinhos — tamanho 23–24**
- **Brinquedo**

Introdução: **Sua presença já faz parte dessa história. Mas, se quiser presenteá-lo, reunimos algumas ideias que combinam com essa fase tão gostosa.**

Fechamento: **O mais importante mesmo é ter você celebrando esse dia com a gente.**
