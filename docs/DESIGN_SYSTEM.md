## Tipografia
Texto sempre HTML/CSS. Direção: manuscrita delicada para destaques, serifada amigável para títulos, sans arredondada para UI/corpo. Sugestões: Caveat, Cormorant Garamond e Nunito.

## Interface
Cantos arredondados suaves, bordas discretas, textura de papel quase imperceptível, sombras leves, botões grandes. Evitar glassmorphism, neon, visual SaaS e excesso de cards.

## Foto do Kalleb
Usar foto real como protagonista no hero. Evitar filtros fortes e preservar o rosto.
